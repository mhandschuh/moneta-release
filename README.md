# Moneta

Share expenses with your partner and with groups, like Splitwise, but the data stays yours: on your phones and,
end-to-end encrypted, on your own server. Split equally, by shares, by amounts or by percent; settle up with the
fewest payments; repeating expenses; foreign currencies at the ECB rate; import from Splitwise.

This repository only holds the installable APKs. Android 11 or newer.

## Install (with automatic updates)

1. Install **Obtainium** from its [releases page](https://github.com/ImranR98/Obtainium/releases)
   (download the `app-arm64-v8a-release.apk`, open it, allow installing from your browser when asked).
2. In Obtainium: **Add App**, paste `https://github.com/mhandschuh/moneta-release`, tap **Add**, then **Install**.
   Allow Obtainium to install apps when Android asks.

Obtainium checks for new versions and shows a notification; tap it to update. Your data stays.

## First steps

- **Joining someone's group:** Settings → Sync → **Cloudflare access**: enter the client ID and secret you were
  given for your phone. Then open the invite link (or Moneta → Join or import → Join with an invite, and paste
  the message). Moneta asks which member you are.
- **Your own group:** New group, or Join or import → Import from Splitwise (a group's CSV export).
